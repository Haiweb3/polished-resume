# Writing Rules

Use these rules when converting raw candidate material into resume copy.

## Bullet rules

- Start with a strong action verb.
- Lead with the most important technical or business outcome.
- Use specific systems, protocols, tools, or scale where that improves credibility.
- Include numbers when they are real and relevant.
- Keep one bullet focused on one claim.

## Prefer

- ownership
- impact
- measurable change
- technical complexity
- system constraints
- decisions with clear rationale

## Avoid

- vague self-praise
- repeated buzzwords
- long background exposition
- bullets that only describe participation
- inflated claims unsupported by the source material

## Compression rules

- Cut repeated context once the section title already provides it.
- Replace long subordinate clauses with tighter nouns and verbs.
- Merge similar bullets when the page is dense.
- Drop low-value bullets before shrinking font size or line height.

## Tone

- professional
- direct
- concrete
- low-fluff

## Section heuristics

- `Education`: keep to one line plus honors only if useful.
- `Skills`: group by category; avoid giant keyword dumps.
- `Projects`: emphasize architecture, optimization, scale, reliability, or shipped outcome.
- `Experience`: emphasize ownership, delivery, and measurable results.
- `Awards`: include only meaningful proof signals.
